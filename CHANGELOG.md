# Changelog

All notable changes to Daymark are documented here.

## 2.1.0

- Added custom timer presets and persistent custom durations.
- Added shortcut editing, task priorities, and bookmark import.
- Added weather condition text, last-updated time, and manual refresh.
- Added balanced, focus, and minimal layout presets.
- Added support for up to five saved wallpapers with daily rotation.
- Added versioned backups and controls to clear local data.
- Added the `Ctrl+Shift+Y` / `Command+Shift+Y` Chrome shortcut to open Daymark.

## 2.0.0

- Added search engine selection, command palette, onboarding, task history, notifications, and accessibility preferences.

## 1.0.0

- Initial release.
