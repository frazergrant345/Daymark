# Contributing to Daymark

## Development

Daymark uses vanilla HTML, CSS, and JavaScript. Load the project folder through `chrome://extensions` with Developer mode enabled, then reload the extension after each change.

## Guidelines

- Keep Daymark fast, local-first, and calm to use as a new-tab page.
- Do not add dependencies or a build step without a strong reason.
- Preserve keyboard access and visible focus states for interactive controls.
- Test changed behavior in Chrome and run `node --check app.js` before opening a pull request.

## Pull Requests

Describe the user-facing change, include before/after screenshots for visual changes, and update the README or changelog when appropriate.
